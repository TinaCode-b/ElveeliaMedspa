# Elveelia Medspa

A modern, elegant, and responsive website for **Elveelia Medspa**, designed to showcase beauty, wellness, and aesthetic services in a clean and welcoming online experience.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern and elegant medspa aesthetic
- Service showcase section
- About section
- Contact information
- Smooth navigation
- Interactive website elements using JavaScript
- Clean HTML, CSS, and JavaScript structure
- Mobile-friendly layout

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layout, animations, and responsiveness
- **JavaScript** — Interactivity and dynamic functionality

## 🚀 Getting Started

To run the website locally:

1. Clone the repository:

```bash
git clone https://github.com/TinaCode-b/ElveeliaMedspa.git
```

2. Open the project folder:

```bash
cd ElveeliaMedspa
```

3. Open `index.html` in your browser.

No additional dependencies or installation are required.
